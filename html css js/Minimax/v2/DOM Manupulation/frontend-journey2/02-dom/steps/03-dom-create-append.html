DOM manipulation · Step 3

Building new elements

So far we only changed things that already existed. Now we make new ones. It is always a two-step dance: create the element, then insert it.

The idea

Step one — create. This makes a brand new element in memory. It is not on the screen yet.

const li = document.createElement("li");
li.textContent = "Buy milk";
li.className = "todo";

Step two — insert. You say where it should go.

const ul = document.querySelector("#list");
ul.append(li);            // add at the end (inside ul)
ul.prepend(li);           // add at the start
li.before(other);         // add as a sibling, before me
li.after(other);          // add as a sibling, after me

ul.appendChild(li);       // older way, same result as append

Only after the insert does the element appear on the page. Until then it exists in memory but is invisible. This is called a detached element.

Why do it in two steps? Because it lets you build the whole element — set its text, its class, its attributes, even attach a listener to it — before it goes anywhere near the screen. Then it appears fully formed, in one move.
