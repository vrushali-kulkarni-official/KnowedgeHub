Functions: a named box of steps

A function is a piece of code you give a name, so you can run it whenever you want, as many times as you want. You already know this from Python.

The idea

You will write the same three lines over and over if you have no functions. A function lets you write them once and call them by name.

function greet(name) {
  return "Hi " + name + "!";
}

console.log(greet("Ada"));   // Hi Ada!
console.log(greet("Alan"));  // Hi Alan!

Three parts, exactly like Python:

  • function + name + (parameters) = the header.
  • the { } block = the body (Python uses indentation instead of braces).
  • return = hand a value back out. If a function has no return, it gives back undefined — which is JavaScript's version of Python's None.

You call it by writing its name with parentheses: greet("Ada"). The values you pass in are arguments.

Python &#8594; JavaScript

Literally the same thing.

Python
def greet(name):
    return "Hi " + name + "!"
→
JavaScript
function greet(name) {
  return `Hi ${name}!`;
}
Python (one-liner style)
greet = lambda name: "Hi " + name + "!"
→
JavaScript (arrow function)
const greet = (name) => `Hi ${name}!`;
Python default arg
def greet(name="friend"):
    return "Hi " + name
→
JavaScript default arg
function greet(name = "friend") {
  return `Hi ${name}`;
}

Arrow functions: the short form you will see everywhere

JavaScript has a second way to write functions, called an arrow function. It is shorter and it behaves slightly differently (you will meet that difference in Step 6).

const add = (a, b) => a + b;          // one-line body
const add = (a, b) => {
  return a + b;
};               // block body
const shout = s => s.toUpperCase();                     // one arg, no parens needed

Rule of thumb: function for named functions you define yourself, arrow functions for short inline callbacks. Both are 100% interchangeable for everything we do in this course — except one case we will hit in Step 6.

Why functions matter for the DOM

Two reasons, and both are about staying organised:

  • Naming a behaviour. A function called addTodo(text) tells you what it does without you reading the body.
  • One job, one place. When a button is clicked you will often need the same three lines of code in two different places. Put them in a function, call it twice.

A function only sends a value back if it says return.

✅ Checkpoint — you now know
  • A function = a named, reusable box of steps.
  • Parameters go in the parentheses; return sends a value back out.
  • No return means the function hands back undefined (like Python's None).
  • Arrow functions are the short form: (a) => a * 2.
