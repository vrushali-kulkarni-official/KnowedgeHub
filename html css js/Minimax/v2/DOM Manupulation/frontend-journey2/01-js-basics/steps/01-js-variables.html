Variables: giving names to things

Before you can change a page you need to be able to hold a value. That is all a variable is: a name you stick on a value so you can use it later.

The idea

Your HTML describes the shape of a page. Your CSS describes how it looks. JavaScript describes what happens.

And to do anything at all, JS needs to hold stuff: a name, a number, a piece of text, an element from the page. A variable is just a name sticker for a value.

let score = 10;
const name = "Ada";

Read it like Python: score is a box. You put 10 inside it, and later you can take it back out by writing score.

Why two keywords? JavaScript lets you protect yourself from typos:

  • const — this name is locked forever. You cannot reassign it. Use this by default.
  • let — this name may change later. Use this only when you really do plan to change it.

If you try to do const x = 1; x = 2; JavaScript stops you with an error. That is a feature. It turns a silent typo into a loud one.

Strings vs numbers: text needs quotes ("Ada", 'Ada'), numbers do not (10). If you write const x = 10 you get the number ten; const x = "10" you get the text ten. They look the same on screen and behave completely differently.

Same idea, different spelling

You already know all of this from Python. The concepts are identical, only the keywords changed.

Python
score = 10
name = "Ada"
→
JavaScript
let score = 10;
const name = "Ada";
Python (locked)
# there is no real const, but the idea exists
SCORE = 10  # by convention only
→
JavaScript (locked)
const score = 10;
// score = 20;  // <- Error!
Python f-string
greeting = f"Hi {name}, you have {score} points"
→
JavaScript template literal
const greeting = `Hi ${name}, you have ${score} points`;

The one new trick: backticks

Python has f"...{name}...". JavaScript does the same thing with backticks and ${}:

const name = "Ada";
const score = 10;
const msg = `Hi ${name}, score: ${score}`;
console.log(msg);   // Hi Ada, score: 10

Rule of thumb: use + to glue two short strings together, use backticks whenever a sentence contains a value. Backticks also let you break a long string across lines, which " cannot do.
