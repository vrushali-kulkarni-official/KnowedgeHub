Events: code that runs when something happens

A page is not static. You click, you type, you scroll. Events are how the browser tells your code that something happened.

The idea

The pattern in one line:

element.addEventListener("click", function (event) {
  // this code runs every time the element is clicked
});

Three pieces, all of them familiar:

  • Which element — the thing the user interacts with.
  • Which event — a name in quotes. "click", "submit", "input", "keydown", "mouseover", "load", "scroll".
  • What to do — a function. The browser calls it for you, later, when the event actually happens.

That third piece is a callback: you hand the browser a function and it keeps it, then calls it at the right moment. This is the single most important pattern in front-end work, so slow down and read the demo below.

The event object

When the browser calls your function it passes in an event object — a snapshot of what happened. You can use it:

button.addEventListener("click", function (event) {
  console.log(event.type);              // "click"
  console.log(event.target);            // the element clicked
  console.log(event.clientX);           // mouse x position
});

event.target is the one you will use most. When you listen on a parent but the user actually clicked a child, event.target tells you the child. (More on that in Act 2.)

event.preventDefault() stops the browser's built-in behaviour. The one you will need: forms. By default, submitting a form reloads the whole page. One call to preventDefault() stops that.

Python &#8594; JavaScript

Python has callbacks too (tkinter, asyncio). Same idea, different spelling.

Python (tkinter)
button.bind("<Button-1>", on_click)

def on_click(event):
    print("clicked!")
→
JavaScript (browser)
button.addEventListener("click", function (event) {
  console.log("clicked!");
});
Python (no event object)
def on_click():
    print("clicked!")
→
JavaScript (event object)
function onClick(event) {
  console.log(event.target);
}

  • addEventListener("eventName", function) is the trigger pattern.
