Lists and dictionaries (arrays and objects)

You need two containers before you touch the DOM: a list of things, and a thing with named properties. In Python you call them list and dict. In JavaScript: array and object.

The idea

Two shapes you will use constantly:

// array = an ordered list
const fruits = ["apple", "mango", "kiwi"];

// object = a set of named properties
const user = { name: "Ada", age: 36, admin: true };

Reading from them:

fruits[0]        // "apple"   (index starts at 0)
fruits.length    // 3
user.name        // "Ada"
user["age"]    // 36

JavaScript lets you use dot notation for objects (user.name) as long as the key is a normal word with no spaces. If the key has a dash or a space you must use square brackets: user["first-name"].

Python &#8594; JavaScript

Your brain already has this model. Just rename the boxes.

Python
fruits = ["apple", "mango", "kiwi"]
length = len(fruits)
first = fruits[0]
→
JavaScript
const fruits = ["apple", "mango", "kiwi"];
const length = fruits.length;
const first = fruits[0];
Python dict
user = {"name": "Ada", "age": 36}
→
JavaScript object
const user = { name: "Ada", age: 36 };
Python loop
for f in fruits:
    print(f)
→
JavaScript forEach
fruits.forEach(function (f) {
  console.log(f);
});
Python list comprehension
big = [f.upper() for f in fruits]
→
JavaScript map
const big = fruits.map(function (f) {
  return f.toUpperCase();
});

Three array methods that will do most of the work

These three replace almost every loop you would write in Python:

const nums = [1, 2, 3, 4, 5];

// forEach: do something with each item (no return needed)
nums.forEach(n => console.log(n * 2));

// map: build a NEW array from each item
const doubled = nums.map(n => n * 2);   // [2,4,6,8,10]

// filter: keep only the items that pass a test
const big = nums.filter(n => n > 3);     // [4,5]

Mental model: map and filter always give you a new array. They never change the original. That is why you usually write const doubled = nums.map(...) and use doubled afterwards.

One important difference from Python: map and filter need a function as their argument. In Python you write f.upper, in JavaScript you write f => f.toUpperCase() (note the arrow).

✎ Your turn: Lists of objects

This is the shape you will meet constantly in the DOM: a list of objects, one object per row in a list.

Hint 1
Inside forEach or map, the arrow function's parameter (u) is one item from the array.
Hint 2
u.name gets the name property off that item.
Hint 3
You can chain: users.filter(...).map(...).

  • Array = list, Object = dict.
