Project: a todo app with zero libraries

Everything so far, combined into one thing you can actually use. No framework, no npm, no build step. Just HTML, CSS and the DOM.

The spec

Build a todo list that has:

  • an input + button that adds a task
  • clicking a task toggles it between done and not done
  • each task has a delete button
  • a footer that says how many tasks are left
  • the list survives a page refresh (localStorage)

Nothing here needs a library. Every single feature above is something you already know how to do.

Milestones - do them in this order

Do not try to write it all at once. Each milestone is a runnable version. Stop at each one and check it works before continuing.

  1. State + render. Make a todos array and a render() function that draws it into a <ul>. Start with two hard-coded todos in the array. Check: do two rows appear?
  2. Add. Wire up the button. Read the input's value, push a new object into the array, call render(), clear the input. Check: can you add five tasks?
  3. Toggle + delete. Use event delegation: one click listener on the <ul>, using event.target.closest(...) to work out what was clicked. Check: can you toggle one row and delete another?
  4. Counter. Show todos.filter(t => !t.done).length in the footer. Computed from the array, not by counting DOM nodes.
  5. Persistence. Save with localStorage.setItem("todos", JSON.stringify(todos)) and load it back on start-up with JSON.parse(localStorage.getItem("todos")). Guard against it being null.

Shape of the data:

let todos = [
  { id: 1, text: "Learn the DOM", done: false },
  { id: 2, text: "Build something", done: false },
];

Give every task an id. You need it to delete the right one, because the index in the DOM is not the same as the index in your array once you start filtering or deleting.

The id trick

Give each item a unique id, and put it in the DOM as a data-id attribute:

li.dataset.id = todo.id;      // writes data-id="1"

// later, in your delegated handler:
const id = Number(item.dataset.id);
todos = todos.filter(t => t.id !== id);

Then dataset.id tells you exactly which task in your array to change. No index maths, no bugs when the list reorders.

    The full solution (read it AFTER you build yours)

    This is one way to do it. Yours will look different — that is fine. Compare the shape, not the letters.

    // ---------- state ----------
let todos = [];
let nextId = 1;

const listEl = document.getElementById("todo-list");
const inputEl = document.getElementById("todo-input");
const countEl = document.getElementById("todo-count");

// ---------- render ----------
function render() {
  // 1. clear the list
  listEl.innerHTML = "";

  // 2. draw one row per todo
  todos.forEach(function (todo) {
    const li = document.createElement("li");
    li.className = todo.done ? "done" : "";
    li.dataset.id = todo.id;

    const label = document.createElement("span");
    label.className = "label";
    label.textContent = todo.text;

    const del = document.createElement("button");
    del.className = "del";
    del.textContent = "x";
    del.dataset.action = "delete";

    li.append(label, del);
    listEl.append(li);
  });

  // 3. update the counter (computed from data, not from the DOM)
  const left = todos.filter(t => !t.done).length;
  countEl.textContent = left + " left";

  // 4. save
  localStorage.setItem("todos", JSON.stringify(todos));
}

// ---------- actions ----------
function addTodo(text) {
  todos.push({ id: nextId++, text: text, done: false });
  render();
}

function toggleTodo(id) {
  todos = todos.map(t => t.id === id ? { ...t, done: !t.done } : t);
  render();
}

function deleteTodo(id) {
  todos = todos.filter(t => t.id !== id);
  render();
}

function clearDone() {
  todos = todos.filter(t => !t.done);
  render();
}

// ---------- events (delegation) ----------
listEl.addEventListener("click", function (event) {
  const delBtn = event.target.closest('[data-action="delete"]');
  if (delBtn) {
    deleteTodo(Number(delBtn.parentElement.dataset.id));
    return;
  }

  const row = event.target.closest("li");
  if (row) toggleTodo(Number(row.dataset.id));
});

document.getElementById("todo-add").addEventListener("click", function () {
  const text = inputEl.value.trim();
  if (text === "") return;
  addTodo(text);
  inputEl.value = "";
  inputEl.focus();
});

document.getElementById("todo-clear").addEventListener("click", clearDone);

// ---------- start up ----------
const saved = localStorage.getItem("todos");
if (saved) {
  todos = JSON.parse(saved);
  nextId = todos.length ? Math.max(...todos.map(t => t.id)) + 1 : 1;
}
render();

    Two things in there you have not seen yet

    You will not understand every line yet, and that is fine. Two highlights:

    • todos.map(t => t.id === id ? { ...t, done: !t.done } : t) — the ... is called spread. It copies an object, so you change the copy and not the original. (We will study it properly in the advanced JavaScript act.)
    • Math.max(...todos.map(t => t.id)) — the ... there spreads an array into separate arguments. Same symbol, different job.

    Both exist to make “change one item in an array” painless. You can also write it the long way:

    todos = todos.map(function (t) {
  if (t.id === id) {
    t.done = !t.done;   // same object, mutated
  }
  return t;
});

    🎯 Tiny challenge

    Once your todo app works, add one of these:

    • Edit: double-click a task's text and change it.
    • Filter: three buttons — All / Active / Done — that show different subsets.
    • Countdown: show “2 of 5 done” as well as “2 left”.
    • Keyboard: pressing Enter in the input adds the task (you already know how — keydown + e.key === "Enter").

    ✅ Checkpoint — you now know

    • You combined state, actions and render into one working app.
    • You used event delegation instead of one listener per row.
    • You compute the counter from the array, not from the DOM.
    • You persisted with localStorage + JSON.
