Server-Sent Events (SSE)

Receive server-pushed updates over one long-lived HTTP connection.

What to notice

  • SSE requires HTTP/1.1+ and works over HTTP/2. It does not work from a file:// page.
  • EventSource auto-reconnects with a backoff, and sends the last id it saw in the Last-Event-ID header — let your server use that to resume.
  • To send auth with SSE you can't set custom headers on EventSource. Use a cookie, or use fetch + ReadableStream (Act 9 Step 9.1) instead.
