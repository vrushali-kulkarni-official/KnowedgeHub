Hold state in a variable, render it, and handle multiple inputs to the same state.

What to notice

  • A disabled button doesn't fire click events — so the counter can't go below zero even if someone calls the handler directly. (Well — it can, if they call the function. Guard in the handler too.)
  • Using textContent (not innerHTML) is right here: the count is data, not markup.
