Project 4 — Dark Mode Toggle

Combine CSS variables, a class on the root element, localStorage, and system preference detection.

What to notice

  • classList.toggle(name, force) — the second argument forces the state to true/false instead of flipping it. Useful for apply(theme).
  • localStorage only stores strings. Storing an object means JSON.stringify on the way in and JSON.parse on the way out.
