Project 1 — Background-Changing Button

The smallest complete interaction: find an element, listen, change it.

What to notice

  • (index + 1) % colors.length wraps around. The modulo operator is how you cycle through a list forever.
  • Setting element.style.X writes an inline style, which beats your stylesheet. If you later try to style it with CSS, use element.style.removeProperty('background-color') or switch to classes.
