Act 8 · Step 8.5

CSRF, SameSite & Tokens

Understand cross-site request forgery and how modern cookies mostly solve it.

What to notice

  • CSRF requires the server to rely on cookies alone. If your API requires an Authorization header (a JWT), CSRF isn't possible — because a cross-site form can't set custom headers.
  • SameSite=None without Secure is rejected by modern browsers.
