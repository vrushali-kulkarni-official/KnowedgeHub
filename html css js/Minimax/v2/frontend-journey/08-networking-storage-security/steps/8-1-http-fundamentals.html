Act 8 · Step 8.1

HTTP Fundamentals

Understand the request/response model well enough to debug any API problem.

What to notice

  • fetch() by default sends Accept: */* and no Content-Type for a GET. Add headers explicitly with headers: { ... }.
  • A 204 response has an empty body — calling response.json() on it throws a JSON parse error. Check response.status === 204 first, or just check response.ok and only parse if there's content.
