Components, Props & State

Learn React's three core ideas, and the rules that govern them.

What to notice

  • Hooks must be called at the top level of a component or a custom hook. Not inside an if, not inside a loop, not inside a callback. React relies on the call order being identical every render.
  • A component's name must start with a capital letter — <mycomponent /> is treated as an HTML tag, not a component.
  • Components must return a single element. Wrap multiple in a fragment: <>...</>.
