Act 11 · Step 11.4

Next.js & shadcn

See the structure of a modern Next.js app with shadcn/ui, and how it uses everything you know.

What to notice

  • The cva function (class-variance-authority) is the variant pattern from Act 3 Step 3.6, packaged. cn() (clsx + tailwind-merge) resolves conflicting Tailwind classes so the last one wins deterministically.
  • shadcn's theme lives in app/globals.css as CSS variables — exactly the Act 3 Step 3.5 approach, with an added .dark class.
  • Next.js has its own Tailwind setup, but the utility vocabulary is identical to Act 3.

  • In the App Router, a folder named page.tsx defines a route; a file named about.tsx inside a folder is just a module.
