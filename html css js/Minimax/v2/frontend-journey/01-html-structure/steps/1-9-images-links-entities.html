Images, Links & Entities

Write accessible images and links, and handle special characters correctly.

What to notice

  • An <img> is a void element — no closing tag.
  • src can be relative (cat.jpg), absolute (/assets/cat.jpg), or a full URL. Relative paths are resolved against the page's URL, not the CSS file's.

Challenge — Accessible media page

Build a short article page:

  1. One <figure> containing an <img> and a <figcaption>
  2. The image needs a meaningful alt, plus explicit width and height attributes
  3. One link to an external site with target="_blank" and rel="noopener"
  4. One link with href="#" as a placeholder
  5. A paragraph containing &, < and > as real characters (not as &amp;)

Then verify: does the alt read naturally when spoken aloud? (Screen readers sometimes say "image of" for you — if yours does, don't start the alt with "image of".)

Stuck? Open the hints
  • <figure> is the container; <figcaption> goes inside it and is automatically associated with the image.
  • The browser converts &amp; to & in the rendered page. If you want a literal ampersand character on screen, write &amp; in the source.
