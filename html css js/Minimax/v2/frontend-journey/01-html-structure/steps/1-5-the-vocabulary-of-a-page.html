The Vocabulary of a Page

Learn the semantic elements, and the one rule that keeps HTML clean forever.

What to notice

  • A semantic element gives you free browser styling (default margins, list bullets, font sizes). You can override all of it — but you get a sane starting point for free.

Live demo — the same nav, two ways

Semantic version (this one):

Home  ·  Docs  ·  About

Div version:

Home  ·  Docs

They look almost identical. But tab through the page with your keyboard: only the first one is focusable, and only the first one is announced as a link.

Challenge — Semantics-only rewrite

Here's a page written as generic divs. Rewrite it using only semantic elements — and no class attributes at all:

<div class="site-header">
  <div class="logo">Acme</div>
  <div class="menu">
    <div class="item">Products</div>
    <div class="item">Pricing</div>
    <div class="item">Contact</div>
  </div>
</div>

<div class="hero">
  <div class="headline">Ship faster</div>
  <div class="sub">Build, test, deploy.</div>
</div>

<div class="page-body">
  <div class="post">
    <div class="post-title">Why we rewrote our API</div>
    <div class="post-body">...</div>
  </div>
</div>

<div class="site-footer">© 2026 Acme</div>

Then answer: which of the original divs did not have a semantic equivalent, and what did you use?

Stuck? Open the hints
  • The logo is a link back home — that makes it an <a>.
  • The last div is genuinely a footer. The others map to <header>, <nav>, <main>, <section>, <article>, <h1>, <p>.
