Challenge — A product card with real states

Build a product card with all of these states:

  • Hover: the image scales up slightly, and a "View" label fades in
  • Focus-visible: a visible ring on the card link (keyboard only)
  • Responsive: full-width on mobile, a 2-up grid from sm, a 3-up from lg
  • Form validation: a price input with a red error message that only appears when the value is invalid

Then tab through your page and check: does every interactive element show a clear focus ring? Does the mouse-click ring disappear?

Stuck? Open the hints
  • For the card hover, put `group` on the card and `group-hover:scale-105` on the image.
  • The error message needs `hidden` by default and `peer-invalid:block` to appear.
