Challenge — A theme that persists

Build a proper theme switcher:

  1. A button that toggles dark mode.
  2. The choice persists across reloads — that means localStorage (Act 4 Step 4.9 will show you the API).
  3. On first visit, respect the OS setting via matchMedia('(prefers-color-scheme: dark)').
  4. Add the anti-flash snippet to the <head> so the page never flashes white.
  5. Use the CSS-variable approach (Approach B) so you only write bg-background and text-foreground once.

Bonus: add a "system" option that follows the OS and updates live when the OS changes.

Stuck? Open the hints
  • `localStorage.setItem('theme','dark')` and `localStorage.getItem('theme')` — you'll use these in the Act 5 dark-mode project too.
  • The anti-flash script must run in <head> BEFORE the stylesheet, so the class is set before the first paint.
