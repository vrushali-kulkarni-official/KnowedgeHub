Reading the Scales

Stop memorising class names individually — learn the scales and the names derive themselves.

What to notice

  • In Tailwind v3+ the space is top-[calc(100%-2rem)]. In v4 the syntax changed to top-[calc(100%-2rem)] with underscores for spaces: top-[calc(100%_-_2rem)].
  • Arbitrary values are an escape hatch, not a default. If you find yourself writing p-[13px] a lot, the scale is wrong for your design — configure a custom one instead.

Challenge — Rebuild a card from the scale

Using only Tailwind utilities (no custom CSS), build a pricing card with:

  • white background, a 1px border in a light grey, rounded corners, a soft shadow
  • padding that steps down to 3 on mobile and 8 on desktop
  • a plan name in small uppercase tracking-wide text
  • a price in text-4xl font-bold with a small "/month" suffix
  • a full-width primary button (indigo background, white text, rounded)
  • a list of features with a green check before each

Then, without changing the design, change the whole card to a dark theme by editing only the colour classes. (You'll automate this in Step 3.5.)

Stuck? Open the hints
  • Responsive padding: `p-3 md:p-8` — the prefix goes before the utility, and the unprefixed one is the mobile default.
  • The checkmark can just be the character ✓ in a <span class="text-emerald-500">.
