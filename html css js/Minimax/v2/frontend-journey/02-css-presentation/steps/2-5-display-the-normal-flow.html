Display & the Normal Flow

Understand the default layout algorithm, and how to take an element out of it.

What to notice

  • Setting width on an inline element does nothing. That's why inline-block exists.
  • You can override a UA default like display: inline on a <span> — but then you're on the hook for all the other inline quirks.

Challenge — A readable article column

Build a page that demonstrates the difference between block and inline layout:

  1. A <div> with a background — show that it fills the width and starts on a new line.
  2. Three <span>s with backgrounds on one line — show that they flow inside the text.
  3. Convert one span to inline-block with a fixed width, and another to display: none. Notice that the second one doesn't leave a gap, but a visibility: hidden one would.
  4. Add a <main> with max-width: 65ch; margin: 0 auto; and put a long paragraph in it. Read it. Compare with the same paragraph at full width.
