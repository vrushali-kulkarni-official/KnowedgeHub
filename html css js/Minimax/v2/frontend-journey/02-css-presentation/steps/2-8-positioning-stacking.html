Positioning & Stacking

Take elements out of normal flow deliberately, and control what paints on top.

What to notice

  • position: fixed is relative to the viewport unless an ancestor has transform, filter or will-change — then it becomes relative to that ancestor. A classic mobile bug: a transform on an ancestor breaks position:fixed.
  • Use inset: 0 as a shorthand for top:0; right:0; bottom:0; left:0.

Challenge — A tooltip and a sticky header

  1. Build a button with a tooltip that appears on hover. The tooltip must be positioned relative to the button, not the page — and it must not affect the layout when hidden.
  2. Make a page tall enough to scroll, and give it a header that stays at the top when you scroll. position: sticky only.
  3. Add a z-index to the header so it passes over the content.
  4. Then break it on purpose: set transform: rotate(0.001deg) on an ancestor of the sticky header and see what happens. Now you know why "fixed" headers sometimes jump around on mobile.
Stuck? Open the hints
  • The tooltip wrapper needs position: relative, and the tooltip position: absolute with bottom: 100% to sit above it.
  • For the sticky header, the parent must not have overflow: hidden — a sticky element can't escape a scroll container that isn't scrolling.
