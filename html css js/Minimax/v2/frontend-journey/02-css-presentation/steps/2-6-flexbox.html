Flexbox

Master the one layout system you'll use every single day.

What to notice

  • Flex items have min-width: auto by default, which means a long unbreakable word can stop them shrinking. The classic fix is min-width: 0 on the item.
  • align-items: stretch (the default) makes all items the same height as the tallest one. flex-start makes them keep their natural height.

Challenge — Build a navbar with flexbox

No float, no position: absolute — flexbox only:

  1. A horizontal bar containing a logo on the left, three links in the middle, and a button on the right.
  2. Make the middle links push the button to the far right (the spacer trick).
  3. Make the whole bar a column layout on narrow screens: logo on top, links below, full width. (Do this with a media query — Act 2 Step 2.9.)
  4. Give the links a gap of 16px and remove all default list bullets and padding.

Extra credit: make the button margin-left: auto instead of using a spacer element. Same result, less markup — when is that better?

Stuck? Open the hints
  • The spacer approach uses flex: 1 on an empty div. The margin-left: auto approach avoids the extra element — the browser pushes the rest of the flex line away.
  • ul has default padding-left and list-style. Reset both: list-style: none; padding: 0;
