Transitions, Transforms & Animation

Add motion that feels good and stays smooth.

What to notice

  • Animating width/height/top/left triggers layout every frame. Animating transform and opacity does not. This is the single most useful performance fact in CSS.
  • The transition shorthand order matters: transition: property duration timing-function;

Challenge — Animate it the right way

Take a card and give it a hover state that lifts it. Then:

  1. Make it lift using transform: translateY().
  2. Now rewrite it using margin-top instead, and open DevTools → Performance while hovering repeatedly. What extra work appears, and why?
  3. Add a smooth transition to the hover state — and notice that if you forget the duration, nothing animates at all.
  4. Add a CSS-only "loading spinner" using @keyframes and animation: ... infinite.
Stuck? Open the hints
  • In the Performance panel, look for yellow "Layout" bars — those are the expensive frames. Animating transform shows purple "Composite" bars instead.
