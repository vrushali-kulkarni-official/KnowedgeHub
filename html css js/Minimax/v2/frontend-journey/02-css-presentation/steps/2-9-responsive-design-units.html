Responsive Design & Units

Write layouts that adapt to any screen, and size things in units that respect the user's settings.

What to notice

  • In DevTools, toggle the device toolbar (the phone/tablet icon) and set a custom width to test breakpoints. You can also type a CSS width directly in the toolbar.
  • prefers-reduced-motion is a media query too — respect it for animations.

Challenge — One layout, three widths

Build a single card component that lays out differently at three sizes without changing its HTML:

  • Under 640px: everything stacked in one column
  • 640px–1024px: image beside the text
  • Over 1024px: image, text, and a sidebar meta column

Then set the page font-size in DevTools to 24px and confirm the layout still works (that's what rem buys you).

Stuck? Open the hints
  • Change the grid-template-columns value at each breakpoint — the HTML doesn't move at all.
  • Using em for the gap inside the card makes the gap scale with the card's font size. Try it.
