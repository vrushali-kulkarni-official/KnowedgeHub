Web Workers

Move CPU-heavy work off the main thread so the page never freezes.

What to notice

  • You can't create a Worker from a file:// page — the browser blocks it (same-origin policy). Serve the folder.
  • A worker script must be a separate file (or a Blob URL). You can't inline it in a <script> tag.
  • Workers have no access to localStorage — use IndexedDB instead, or pass data via postMessage.

Stuck? Open the hints
  • In the worker, self is the global object (like window in the main thread). Use self.onmessage = (e) => { self.postMessage(result) }.
  • worker.terminate() kills the thread immediately — there's no graceful shutdown.
