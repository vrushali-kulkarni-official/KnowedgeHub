Webhooks, End to End

See how a server receives a third-party event and pushes it to a browser.

What to notice

  • Webhooks are at-least-once delivery — providers retry on failure, so you'll get duplicates. Use the event id to deduplicate.
  • Verify the signature with a timing-safe comparison, and never log the full secret.
  • For local testing, most providers have a CLI (e.g. Stripe CLI) that can forward real webhook events to your machine.
