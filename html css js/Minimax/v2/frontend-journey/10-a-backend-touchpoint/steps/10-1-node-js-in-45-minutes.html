Node.js in 45 Minutes

Understand the runtime, the event loop, and enough Express to serve an API.

What to notice

  • express.json() is middleware — it must be registered before the routes that need it, or req.body will be undefined.
  • Node's process.env holds environment variables. Never hard-code secrets.
  • app.use(express.static('public')) serves a folder of static files — that's how you serve a front end from the same origin as your API (and skip CORS entirely).
