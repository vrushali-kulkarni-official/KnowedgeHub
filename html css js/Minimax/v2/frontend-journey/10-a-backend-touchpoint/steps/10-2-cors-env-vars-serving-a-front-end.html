CORS, Env Vars & Serving a Front End

Configure the things the browser insists on: CORS headers, environment variables, and static hosting.

What to notice

  • The manual CORS middleware must handle OPTIONS itself — the browser's preflight never reaches your route handlers otherwise.
  • res.setHeader before res.json() — once the response is sent, headers can't be changed.

Stuck? Open the hints
  • Two servers on different ports = different origins = CORS applies. Same port = same origin = CORS doesn't apply.
  • The ETag can be a hash of the body: crypto.createHash('md5').update(body).digest('hex')
