Act 4 · Step 4.9

Functions

Write functions in all three JS forms and know exactly when to use each.

What to notice

  • A function without an explicit return returns undefined — not null, not an empty object.
  • Arrow functions have no arguments, no prototype, and can't be new'd. They're not a drop-in replacement for regular functions in every position.

Stuck? Open the hints
  • The detached call fails because this depends on the call site — called as a bare function, this is undefined in strict mode.
  • An arrow function defined inside a method captures the method's this, so it survives detaching.
