Act 4 · Step 4.2

Values & Variables

Learn <code>let</code>, <code>const</code>, <code>var</code> — and why one of them is basically banned.

What to notice

  • JavaScript has no separate "undeclared" error at runtime by default — assigning to an undeclared variable in sloppy mode creates a global. In modules and strict mode it throws a ReferenceError. Always declare your variables.
  • let a = 1, b = 2; declares two variables in one statement — but one statement per line reads better.

Stuck? Open the hints
  • #1 throws ReferenceError: Cannot access 'a' before initialization. let is hoisted but not initialised — using it before its declaration is a ReferenceError, not undefined.
  • #2 throws a SyntaxError — you can't have two let b in the same scope. Try var b = 1; var b = 2; instead.
