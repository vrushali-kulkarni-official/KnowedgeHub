Types & <code>typeof</code>

Know every type JavaScript has, and that only one of them is really dynamic.

What to notice

  • typeof on an undeclared variable returns "undefined" instead of throwing — that's a deliberate feature, used to check whether a global exists.
  • Arrays report typeof === "object". To test for an array specifically, use Array.isArray(x).

Stuck? Open the hints
  • Dates and arrays are both objects. Object.prototype.toString.call([]) gives "[object Array]".
  • A DOM element is an object, not a string — a very common assumption to unlearn.
