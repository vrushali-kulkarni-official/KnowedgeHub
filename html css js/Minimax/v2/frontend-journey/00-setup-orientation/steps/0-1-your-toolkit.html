Act 0 · Step 0.1

Your Toolkit

Get a working editor + browser + DevTools loop, and understand the four DevTools panels you'll actually use.

What to notice

  • DevTools' Elements panel shows the DOM after the browser has parsed it — which is not always identical to your source file.
  • The Console doubles as a REPL: you can type JavaScript there and evaluate it instantly against the current page.

Try it right now

  • Press F12 and open the Console tab.
  • Type document.title and press Enter. That is JavaScript, running against this page.
  • Switch to Elements, right-click this paragraph, choose Inspect.

Challenge — Get the loop working

  1. Open this file in Chrome/Edge with F12 open on the right side.
  2. In the Console, run document.querySelectorAll('p').length — what does it tell you, and why might it differ from the number of <p> tags in the source file?
  3. Right-click a paragraph → Inspect. In the Elements tree, use the small </> icon to expand a node and see its children.
  4. Create a new file scratch.html next to this one with a <h1> and two <p> tags, open it, and repeat the exercise. Now you can build your own feedback loop.
Stuck? Open the hints
  • document.querySelectorAll returns a live collection of every element matching the selector in the current DOM.
  • If the counts differ, the browser probably added or removed an element while parsing — which is exactly what Act 1 Step 1.4 is about.
