Act 0 · Setup

Start here

This page is your orientation. Read it once, then open 01-html/lesson.html and we'll begin.

What you need (5 minutes, one time)

  1. An editor. VS Code is the standard and free. If you already use something else, that's fine — nothing in this course is VS Code specific.
  2. A browser. Chrome or Edge, so you get DevTools built in. F12 opens it on Windows/Linux, ⌥⌘I on Mac.
  3. Nothing else. No npm, no build step, no server. For the first several acts you just double-click an .html file and it runs.

Two habits from day one

  1. Keep DevTools open in a side panel. You will use it every single step, starting now. The Elements tab shows you the live DOM — the tree your HTML actually became.
  2. Write code by hand. Typing the examples matters more than reading them. Small edits, break things on purpose, see what happens.

How we work together

  1. I teach one concept and give you one file.
  2. There's a challenge at the end of each file. It takes 5–15 minutes.
  3. You do it and paste your code (or just describe the result).
  4. I review it like a code reviewer — what's good, what's subtle, what's next.
  5. Then we build the next concept on top of that one.

How this course differs from a docs site

You're not going to get a list of every property of every API. You already know how to program; what you're missing is the web's mental model. So we go deep on the things that actually matter in production, skip the trivia, and always connect a new idea to something you already know from Python.
