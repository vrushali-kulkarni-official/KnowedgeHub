# Module 2 — Document Loaders

The data layer of RAG. Loaders turn the mess of real-world formats
(PDF, DOCX, web, CSV, GitHub, ...) into a clean `list[Document]`
that the rest of the pipeline can consume.

## What is a `Document`?

```python
from langchain_core.documents import Document

doc = Document(
    page_content="StarTrack-9 uses reinforcement learning...",
    metadata={"source": "s3://docs/spec.pdf", "page": 14},
)
```

That's it. Two fields. Everything in LangChain is built on this pair.

## Common gotchas (the ones that bite in production)

1. **Encoding**: `encoding="utf-8"` is the right default. Windows-era
   files in cp1252/latin-1 will mangle. If you see `Ã©` instead of `é`,
   wrong encoding.

2. **Scanned PDFs**: PyPDFLoader returns empty `page_content`. You need
   OCR (UnstructuredPDFLoader + Tesseract). We cover this later.

3. **JS-rendered web pages**: WebBaseLoader can't execute JS. Use
   `FireCrawlLoader`, `PlaywrightURLLoader`, or `AsyncChromiumLoader`.

4. **GitHub rate limits**: 60 req/hr unauthenticated. With a PAT it's
   5000/hr. Free, just create one.

5. **Pickle trust**: `FAISS.load_local()` requires
   `allow_dangerous_deserialization=True`. NEVER set it for indexes
   you didn't build yourself.
